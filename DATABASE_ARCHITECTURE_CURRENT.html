Schema design considerations

PostgreSQL PatternMongoDB Consideration
Quotation.id is already CUID string✅ Natural fit for MongoDB _id
Integer SERIAL PKs (Product, Category etc.)⚠️ MongoDB uses ObjectId — integer IDs need explicit handling
JSONB columns (config, variantConfig, matrixDimensions)✅ Direct native fit for MongoDB document model
PostgreSQL native ENUMs❌ No native enums — must enforce via Zod/Mongoose at app level
DECIMAL(10,2) for prices⚠️ Float precision — careful handling needed (Decimal128)
FK constraints (CASCADE/RESTRICT)❌ No FK enforcement in MongoDB — app-level only
HouseTypeRoomTemplate (join table)✅ Embed as array inside HouseType document
QuotationRoom + QuotationItem hierarchy✅ Strong candidate for embedding rooms with nested items in Quotation
